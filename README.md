📚 RAG-Based Question Answering System

🚀 About the Project

This project is a Retrieval-Augmented Generation (RAG) based Question Answering System that allows users to ask questions from a PDF document and receive relevant, context-based answers.

The system retrieves relevant information from the uploaded document and uses it to generate meaningful responses.

🎯 Project Objective

The main objective of this project is to make document-based information retrieval easier and faster using Artificial Intelligence and Large Language Models (LLMs).

✨ Features

- PDF document-based question answering
- Automatic information retrieval
- Context-aware AI-generated responses
- Semantic search capabilities
- Easy-to-use question-answering interface

🛠️ Technologies Used

- Python
- LangChain
- Large Language Models (LLMs)
- Vector Database
- PDF Document Processing
- Embeddings

⚙️ Installation and Setup

Step 1: Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

Step 2: Open the project folder

cd Rag-Project

Step 3: Create a virtual environment

python -m venv venv

Step 4: Activate the environment

Windows:

venv\Scripts\activate

Step 5: Install dependencies

pip install -r requirements.txt

Step 6: Run the project

python main.py

💡 How It Works

1. The PDF document is provided as the knowledge source.
2. The document content is processed and converted into embeddings.
3. Relevant information is retrieved based on the user's question.
4. The retrieved context is used to generate an accurate response.
